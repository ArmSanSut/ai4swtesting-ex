## ✅ File upload test cases

The prompt and a complete response are already captured in a1-1.md. A concise version of the test ideas is:

- Upload a valid file and confirm it is saved exactly as provided
- Submit the form without attaching a file
- Upload an empty file
- Upload a file at the size limit
- Upload a file above the 20 MB limit
- Upload an unsupported file type
- Upload a file with a mismatched extension and content type
- Upload files with spaces, Unicode characters, or long names
- Attempt path traversal via names like ../
- Upload a duplicate filename and verify overwrite or rename behavior
- Interrupt the upload mid-transfer
- Simulate storage or server failure and verify the failure is reported correctly

> This is the kind of broad checklist that is useful for a first-pass test plan, but it still needs the actual app details and test framework to become runnable automated tests.
