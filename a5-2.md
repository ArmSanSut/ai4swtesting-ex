# Activity 5 – Step 2: With examples (few-shot)

**Chatbot / model:** <!-- e.g., ChatGPT (GPT-5), Gemini, Claude / เช่น ChatGPT (GPT-5), Gemini, Claude -->

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
For example:
* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [EP] no digit ("SecretPass") → rejected
```

## Response

- [BVA] 7 characters, one below the minimum ("Abcde1X") → rejected
- [EP] no digit ("SecretPass") → rejected
- [EP] no uppercase letter ("secretpass1") → rejected
- [BVA] 8 characters exactly, valid with an uppercase letter and a digit ("Abcde1Xy") → accepted
- [BVA] 20 characters exactly, valid with an uppercase letter and a digit ("A1234567890bcdefghij") → accepted
- [BVA] 21 characters, one above the maximum ("A1234567890bcdefghijk") → rejected
